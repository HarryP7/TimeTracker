# TimeTracker

Десктопное приложение на C# для записи времени выполнения задач.

## Структура папок проекта

•	📁 Data — контекст БД.  
•	📁 Models — описание сущности задачи.  
•	📁 ViewModels — логика приложения (таймеры, команды кнопок).  
•	📁 Views — визуальный интерфейс (окна).
